RK3588 WebFlasher

rockusb over WebUSB · Go/WASM 核心 · M3b（uf 写入 + 镜像自带 loader + 上机前自检）

无设备 core 加载中
本页会写 flash。 Download Boot 只用 EP0 vendor request 把 镜像自带的 loader 写进 maskrom RAM；随后的 gpt / wl / rd 由 internal/uf 的同一套状态机执行。写入前必须逐项通过下面的自检； 上电后的第一条命令必须是 db，在它成功之前页面会禁用所有会发 CBW 的按钮。

1 · 设备

首次使用点“授权设备”，在浏览器弹窗里选 0x2207 设备。设备重新枚举（maskrom → loader）后浏览器会撤销按实例的授权， 需要再次点授权；页面会在 connect 事件后自动重新 ld。

2 · 镜像与 loader

默认使用镜像自带的 loader（RKFW 头的 loader offset/length），页面会切出来并显示 sha256、长度和 LDR 构建日期， 再与镜像的 chip 比对。需要时可手动指定别的 loader，但会被标记“非镜像自带”——真机上错配的 loader 会在 index 0 被 BootROM 拒收。
