RK3588 WebFlasher

rockusb over WebUSB · Go/WASM 核心 · M4（可安装 PWA、离线、官方 zip 直读）

无设备 core 加载中 在线
本页会写 flash。 Download Boot 只用 EP0 vendor request 把 镜像自带的 loader 写进 maskrom RAM；随后的 gpt / wl / rd 由 internal/uf 的同一套状态机执行。写入前必须逐项通过下面的自检； 上电后的第一条命令必须是 db，在它成功之前页面会禁用所有会发 CBW 的按钮。

安装与离线（PWA）

安装后从桌面/开始菜单打开，断网也能载入页面与 wasm（安装本身不授予设备权限）。

离线：检查 service worker…

只有 Chromium 内核（桌面 Chrome / Edge、ChromeOS、Android Chrome）有 WebUSB；Safari 与 Firefox 既不能写入，也无法安装本页。驱动与 udev 规则见 docs/webusb-drivers.md。

1 · 设备

设备重连向导

    首次使用点“授权设备”，在浏览器弹窗里选 0x2207 设备。设备重新枚举（maskrom → loader）后浏览器会撤销按实例的授权， 需要再次点授权；页面会在 connect 事件后自动重新 ld。

    2 · 镜像与 loader

    官方 .zip 可以直接选：页面只在中央目录里定位首个 RKFW 条目，再用 DecompressionStream('deflate-raw') 按需解压（ZIP64 也支持），不落地 3.8 GiB — 解出来的字节与同一份 .img 完全相同，所以计划逐字段一致。
