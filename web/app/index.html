RK3588 WebFlasher

rockusb over WebUSB · Go/WASM 核心 · M1（ld / cd / sd / db / info）

无设备 core 加载中
只写设备 RAM，不写 flash。 db（Download Boot）只会用 EP0 vendor request（0x40/0x0C，index 0x0471/0x0472）把你本地选择的 loader 分块写进 maskrom 的 RAM； 本阶段没有 uf、没有擦除、没有 flash 写入、没有复位。loader 由你提供，工具不分发。

1 · 设备

首次使用点“授权设备”，在浏览器弹窗里选 0x2207 设备。设备重新枚举（maskrom → loader）后浏览器会撤销按实例的授权， 需要再次点授权；页面会在 connect 事件后自动重新 ld。

2 · loader（本地文件）

需要 RK3588 的 RKBOOT loader，例如 rk3588_spl_loader_v1.06.111.bin（约 140 KiB）。 选择后立即在本地校验 tag / CRC-32 / 段表 / 芯片，不会联网、不会上传。
